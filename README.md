## 📚 Topics Covered

### 1. Assignment Operators

Assignment operators are used to assign values to variables and update the value of a variable.

The following operators are practiced:

* `=` — Assignment
* `+=` — Addition Assignment
* `-=` — Subtraction Assignment
* `*=` — Multiplication Assignment
* `/=` — Division Assignment
* `%=` — Modulus Assignment
* `//=` — Floor Division Assignment
* `**=` — Exponentiation Assignment

### 2. Composite / Compound Operators

Composite or compound operators combine an arithmetic operation with assignment.

Examples:

```python
x += 5
y -= 5
z *= 5
a /= 5
b %= 3
c //= 8
d **= 5
```

### 3. Bitwise Operators

Bitwise operators perform operations directly on the individual bits of integer numbers.

The following bitwise operators are practiced:

| Operator | Name        |            |
| -------- | ----------- | ---------- |
| `&`      | Bitwise AND |            |
| `        | `           | Bitwise OR |
| `^`      | Bitwise XOR |            |
| `~`      | Bitwise NOT |            |
| `<<`     | Left Shift  |            |
| `>>`     | Right Shift |            |

### 4. Number Systems

The homework also covers the basic number systems used in computing:

1. Decimal

4. Hexadecimal

Binary representation is particularly important for understanding bitwise operations.
